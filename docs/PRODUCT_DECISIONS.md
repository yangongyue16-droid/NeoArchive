# NeoArchive 已确认产品要求

更新日期：2026-08-14

这份文档是长期开发的单一事实来源。新对话应先读这里，再改代码。后续拍板只追加或改写本节，不要散落在聊天记录里。

## 产品定位

- 本地优先的《Blue Archive》风格剧情编辑器 + 播放器。
- 编辑预览和成品播放共用同一套 `StoryRuntime` 与工程数据。
- 不把第三方游戏素材打进发行包。

## 工作区：幕前 / 幕后

| 页 | 职责 |
| --- | --- |
| 幕前 | 观众看得到的内容：场景、人物、对白、场间怎么切 |
| 幕后 | 呈现参数：字体、比例、分辨率、背景填充、对话框布局 |

- 幕前左栏只管理场景：名称、AUTO 停留、下一场、切场方式、删除。
- 幕前不要出现对话框字号/位置编辑，也不要在场景栏里改对白布局。
- 对白正文在底部时间线选中后，用右侧属性面板改说话人、身份、文本。
- 幕后才改字体、画面、对话框样式；改完应立刻反映在预览上。

## 对白播完停留

文本/语音播完后，再等自定义秒数切下一句。幕前、幕后、「播放场景」、成品播放读同一份工程数据。

- 单句：`dialogue.show.holdAfterMs`（毫秒）。幕后选中该句后改「本句播完停留」。幕前属性面板也能改。
- 场景默认：`scene.autoAdvanceMs`。单句留空就用这个。
- 两者都空：按字数算，`max(850, 字数 × 42)` ms。
- 成品播放默认开 AUTO：字出完后再等停留时间自动切下一句。底部「自动」可关，关了才要点击。
- 编辑器点「播放场景」同样自动切；点选时间线预览不自动切。
- 幕后改样式或停留时，不要把正在播的场景打回旧预览。进「播放成品」前先立刻写下草稿。

## 素材

- 背景：内置图 + 本地图片/视频。
- 音频：BGM / 语音 / 音效都可选手动文件。
- 字体：默认 `Blueaka.ttf`；幕后可再选本地 ttf/otf/woff。
- 本地素材存在本机 IndexedDB，关软件后仍可用。

## 画面

- 工程级比例：16:9 / 21:9 / 4:3 / 3:2 / 1:1 / 9:16 / 自定义宽高。
- 幕前、幕后、成品播放都按同一套 `stage` 铺满可用区域，保持比例。
- 窗口本身不是 16:9 时，容器外可以留边；画面内部必须是设定比例。
- 背景填充（图片和视频共用）：
  - 完整显示 · 不裁切（默认）
  - 铺满画面 · 可能裁切
  - 拉伸填满

## 对话框

当前默认（用户在幕后调好后固化）：

```text
heightPercent: 51
speaker:  fontSize 48, x 9.7,  y 41.68
subtitle: fontSize 40, x 18.61, y 39.97
text:     fontSize 33, x 9.64,  y 58.67
rule:     x 9.54, y 55.17, width 72
```

- 说话人、身份、正文、分割线各自独立位置，不互相锁定。
- 幕后可拖拽调节；数字支持 0.1 步进的无级坐标。
- 「全部应用」把当前对话框样式作为全工程样式。
- 字号按画面宽度相对 1920 等比缩放，避免幕前预览小、幕后预览大时错位。
- 分割线必须保留，且可单独移动、改长度。

## 场间过渡

- 属于幕前场景属性，不是时间线里的「+ 过场」。
- 选下一场后，再选切场：无过渡 / 黑幕 / 白幕 / 档案闸门 / 光环 / 时序轮盘。
- 无过渡：立刻切，不播动画。

## 对白行语音

数据只记入点，不改源文件。

- 字段：`voiceAssetRef` + `voiceStartMs`（毫秒）。成品和「播放场景」播到该句时，从入点起播到文件结尾。
- 语音只跟这一句对白走。切到下一句、切背景图、切角色、切场或点时间线里别的行时，上一条语音必须停。没有语音的对白不能接着播上一句的声音。
- 不裁剪、不另存一份音频。前 3 秒气口/瑕疵用入点跳过即可；「复位起点」把入点改回 0，源文件始终完整。
- 幕前点选对白行、点「刷新当前行」：只预览画面和文本，不播语音。编辑器里点到别的行，试听也停。

### 左侧图标与二级菜单

- 每条对白行开头有独立语音状态图标。
- 未绑定：灰色默认。已绑定音频并设好入点：高亮描边/发光。
- 点图标只展开/收起该行二级菜单，不自动播。各行互不影响。
- 菜单内容：文件名、选择语音、试听/暂停/停止、总览波形、细分波形、「设为成片起点」「复位起点」、清除、收起。

### 试听运输控制

| 操作 | 行为 |
| --- | --- |
| 试听 | 从成片起点开始播。暂停后再点「继续」，从当前位置接着播。 |
| 暂停 | 停在当前位置，不丢进度。 |
| 停止 | 停掉并回到成片起点。和暂停不是一回事。 |
| 设为成片起点 | 把**当前位置**写成 `voiceStartMs`。源文件不动。 |
| 复位起点 | `voiceStartMs = 0`。 |

### 波形：总览 + 细分

两条轨，职责分开，松手后细分窗口不收回。

| 轨 | 作用 | 拖动改什么 |
| --- | --- | --- |
| 总览 | 整段音频，只预览和定位。框出当前细分窗口。 | 播放头 + 细分窗口中心。不改成片起点。波形始终是整段，不会切成滚动视图。 |
| 细分 | 总览框住的那一段放大。 | 直接改 `voiceStartMs`（成片起点）。 |

- 黄线：成片起点。白线：当前预览位置。
- 「设为成片起点」把白线位置写入入点。「复位起点」入点回 0。
- 试听时总览仍是整段；播放头在总览上走，细分窗口保持上次拖到的位置。

实现入口：`src/editor/VoiceCuePanel.tsx`。播放入点：`StoryRuntime` 成品路径读 `voiceStartMs`；编辑器 `preview()` 故意不挂语音。

## 编辑器交互

- 编辑器预览点击画面不推进下一句。
- 成品播放器点击画面仍可推进。
- 撤销/重做、本地草稿自动保存保留。

## 播放器

- 入口用 hash：`#/player`。打包后的 exe 没有 `/player` 路径，pathname 路由会黑屏。
- 「播放成品」必须真正切到播放页，不能只改地址不换界面。
- 进入播放后走独占全屏，连任务栏一起藏掉，方便按 16:9 录屏。
- Esc 或「退出全屏 / 显示 UI」退回窗口模式。
- 普通最大化不是全屏，不要把它当成藏任务栏。

## 以后怎么查看工程

工程不在 Git 仓库里。源代码是编辑器，故事在本机。

| 位置 | 是什么 | 怎么打开 |
| --- | --- | --- |
| 软件里直接看 | 自动草稿，改一下就存 | 打开 NeoArchive 就是当前稿 |
| 「导入」选 `.neoarchive.json` | 下载的 JSON 备份 | 顶部「导入」 |
| 「打开」 | Python 工程库里的正式保存 | 顶部「打开」（后端在线时） |

当前本机约定：

- 正在做的工程名：`新的约定`（`projectId` 仍是 `neoarchive-sample`）。
- 自动草稿：桌面版 Local Storage，键名 `neoarchive:project-draft:v1`。
- 昨晚下载备份：`C:\Users\Administrator\Downloads\新的约定.neoarchive.json`。
- 正式库目录（点过「保存」且后端成功时才有）：`%LOCALAPPDATA%\NeoArchive\NeoArchive\projects\`。
- 本地图片/语音不在 JSON 里，只记 `user:……` 编号，文件在本机 IndexedDB。换电脑或清数据后，工程还能开，素材要对过才能播。

以后新对话先读这份文档，再看软件里的当前草稿；不要把聊天记录当工程。

## 构建约定

- Windows 桌面：`src-tauri/target/release/neoarchive.exe`
- 安装包：`src-tauri/target/release/bundle/nsis/NeoArchive_0.1.0_x64-setup.exe`
- 用户能看见的改动做完后，默认再打一版桌面 exe 并打开，方便当场验收。不要等用户再催「打包打开」。
- 打之前先结束旧 `neoarchive` 进程，避免占用文件。
- 打包：`npm.cmd run build:desktop`（PowerShell 不要直接跑 `npm`）。
- 打开：`Start-Process src-tauri\target\release\neoarchive.exe`
- 只改文档、注释、测试、不进 exe 的内容时，不必打包。

## 明确不做 / 已否决

- 不要用点击编辑器画面来切下一幕。
- 不要在幕前场景栏编辑对白布局。
- 不要把场间过渡混回时间线模块。
- 「回车」只是误输入，不绑定快捷键。
