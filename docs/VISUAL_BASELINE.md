# NeoArchive 视觉基准

## 单人对话立绘

单人角色使用可见区域中心作为坐标锚点，默认参数为：

- X：50%
- Y：80%
- Scale：165%

这组参数是当前 Sakurako 教室对话场景确认的视觉基准。后续单人镜头先从该基准开始，再根据角色体型与构图需要微调。

对白 UI 保持底部渐变式布局；调整立绘时不改动对白 UI。

对白文字组（角色名、学校名、分隔线与正文）相对旧版整体上移 28px；继续箭头独立固定在右下。底部遮罩采用渐进式深蓝渐变，不使用独立卡片覆盖剧情画面。

正文使用 `clamp(13px, 1.25vw, 17px)`，行高为 `1.6`；角色名与学校名维持原尺寸。

## 编辑器壳

应用壳遵循 ArcTavern 的 `heyrico-clean-ui` 产品 UI 规范：

- SF Pro / 系统字体，仅使用 regular 与 medium 字重
- 字阶限定为 12、13、14、16、18、24px
- 三段灰阶信息层级，品牌色仅用于少量实时状态与舞台功能提示
- 导航采用 8px 内边距，面板采用 16px 内边距
- 主操作使用胶囊按钮；面板保持平面与发丝边框

这些规则仅约束编辑器壳，不覆盖剧情舞台内的游戏 UI。

当前编辑器采用 Night 版本：页面背景 `#121212`、面板 `#181818`、选中态 `#212121`，文字层级使用 `#FFFFFF / #EEEEEE / #B5B5B5`。剧情舞台内部保持原有画面与对白配色。

顶部栏提供“日间 / 夜间”文字分段切换器，并将选择保存至浏览器本地存储；初次打开默认使用夜间模式。主题切换仅作用于编辑器壳。
