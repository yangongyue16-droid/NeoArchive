# 背景特效

背景剧本行支持 `effect: { kind, intensity, speed }`。`kind` 为 `glitch`、`vhs`、`droplets`、`frost` 或 `shatter`；强度 0–2，速度 0.25–3。缺省或 `null` 表示关闭。选中背景行后在「背景特效」中调整，设置进入草稿、JSON、后端工程、播放包和运行时存档。

默认只处理图片／视频背景。勾选「覆盖对白文字」后，`effect.coverDialogue: true` 会将背景、可见角色和当前对白合成到特效纹理，使特效也覆盖对白；选项和操作控件仍独立绘制。旧工程缺省关闭。新的背景行会替换此前效果；没有效果的背景行会关闭旧效果。点击「刷新当前行」可重播。强度为 0 不分配 GPU 引擎。

## 来源与适配

五个 WebGL2 引擎来自 [Canvas UI](https://github.com/DavidHDev/canvas-ui)，固定源版本 `44de3787b77d78477a7c03a4c81a7d5ea317cdbc`。保留 [MIT + Commons Clause 许可](../src/effects/canvasui/LICENSE.md)，引擎仅作为 NeoArchive 应用的一部分使用。

`src/effects/canvasui/` 保留上游着色器与效果算法；适配代码使用已有图片／视频的 Canvas2D 纹理替代实验性的 HTML-in-Canvas 捕获，不需要浏览器实验开关。保留纵横比、裁剪方式和背景淡入透明度。五个引擎独立懒加载，像素比上限 1.5，输出长边上限 1600 像素。

图片仅在素材、尺寸或淡入透明度变化时更新纹理，视频随当前播放帧更新。卸载取消动画与监听、释放纹理及上下文；页面隐藏时暂停。减少动态效果偏好启用时停用效果。WebGL2 不可用、上下文丢失、跨域纹理受限等失败保留原背景并显示状态，不阻断剧情。

## 验证

- 前端：参数边界、旧工程、JSON 往返、运行时预览复用、存档、纹理裁剪、StrictMode、异步卸载、参数热更新、零强度、失败回退、减少动态效果。
- 后端：四种效果保存／读取／ZIP 导出往返，以及无效参数拒绝。
- 浏览器：依次选择四种效果；检查强度 0、恢复强度、播放器回放及刷新页面后参数保留。

浏览器中的效果验证不等同于 Tauri Windows/macOS WebView 或不同显卡上的性能验证。外部背景素材仍受浏览器同源限制。

## 对白覆盖

对白纹理按现有 DOM 的字形位置绘制，包含说话人、身份、正文、分割线和对话底色。逐字内容、换行、布局、字体加载与缩放变化会使缓存失效；不替换原 DOM，因此关闭、减少动态效果或渲染失败时原文字立即恢复，选择按钮保持可操作。Spine 在捕获前同步绘制当前帧，以避免 WebGL 缓冲区清空造成角色丢失。覆盖模式的纹理刷新成本高于仅背景模式。

## Shatter 与角色效果

Shatter 复用 Canvas UI 同一固定版本的玻璃碎片着色器。强度控制全屏碎片抬起、散开程度，速度控制漂浮；鼠标可局部抬起碎片。当前是可持续的破碎画面，不是炸碎后切换场景的一次性转场。

角色入场行新增 `characterEffect`（缺省/null 为关闭），支持 `glow`、`glitch`、`dissolve`，强度 0–2、速度 0.25–3。这是 NeoArchive 原生 PixiJS 滤镜，不是对 Canvas UI Particle Object 的移植；保持 Spine 动画及透明度，不引入 Three.js。消散通过强度选择保留比例，速度控制边缘闪动，不自动推进消散进度。滤镜随角色卸载销毁，强度 0 或减少动态效果设置生效时移除；角色坐标/动画更新保留特效。


## 光环与普通立绘蒙版

辉光保持原立绘单独绘制，在其下方分别渲染人物和光环的辉光。`characterEffect.halo.mode` 为 `off`（缺省）、`follow` 或 `custom`；独立模式拥有自己的 `color`、`intensity`、`speed`。关闭的是附加辉光，不隐藏原图光环。滤镜继承渲染器分辨率及抗锯齿设置。

Spine 按 slot、骨骼或 attachment 名称中的 `halo` / `光环` 分离；当前 Sakurako 的 `Halo_01`、`Halo_02` 已验证。其他没有这些命名的 Spine 不会自动进行语义识别。

普通立绘通过「导入立绘图片」进入，辉光下可导入独立蒙版图片，写入 `characterEffect.haloMask: { assetRef, invert }`。白色选择光环，黑色或透明区域选择人物，灰度/透明度提供软边；反转交换选区。蒙版缩放对齐原图全画幅并随立绘移动、缩放，建议使用与立绘相同尺寸和构图的蒙版。无蒙版时全图作为人物；蒙版读取失败时保留原图并关闭附加辉光。当前提供图片蒙版导入，不包含画笔编辑。

立绘和蒙版沿用现有本地 IndexedDB 素材库，刷新后恢复。工程 JSON/后端 ZIP 保存参数与引用；现有 ZIP 导出器尚不收集本地素材文件，因此不保证换设备后仅导入 ZIP 即能恢复这些图片。
