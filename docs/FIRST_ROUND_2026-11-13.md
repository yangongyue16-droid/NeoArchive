# 第一轮编辑器与播放器改进

工作目录：`G:\NeoArchive`。起点：`72ea55d`，开始时 Git 工作区干净。本报告记录功能验证阶段，当时尚未提交、推送或发布。

## 已实现

1. 保留原有 21:9 舞台预设，统一可见/隐藏播放器 UI 时的容器适配计算；补充编辑器网格的最小高度约束。修复重新打开工程时把 `contain` 背景填充强制改成 `cover` 的问题。
2. 语音面板增加毫秒起止输入、选段时长与播放状态、从播放头试听、终点前 0.8 秒试听。拖动、数值输入和播放头设点共用边界校验，防止倒置/空选段；更换语音会清除旧终点。试听与成片播放均按终点截断，成片结束事件只通知一次。
3. Spine 角色使用逻辑舞台尺寸，避免设备像素比重复计入；先同步画布大小再计算角色位置，覆盖编辑区容器变化。浏览器全屏使用明确按钮，桌面仍自动请求全屏；失败不再伪报成功，外部退出全屏会同步按钮状态。隐藏 UI 后不再由静止指针立即展开。
4. 在现有等待 Cue 上新增 `blank`。属性面板可设置黑屏时长，也可切换等待玩家点击；本地草稿、JSON、后端模型、OpenAPI/客户端和工程仓库均支持保存。黑屏时移除当前对白语音和对白，保留舞台及 BGM，计时后按下一条 Cue 继续。

## 边界与后续

- 没有实现“先背景、后对话框”的分阶段定格或对白延迟方案。
- 本轮空白页采用黑屏；结束后恢复既有舞台，由下一条 Cue 决定后续内容。
- 背景视频仍沿用原有 `object-fit` 与播放结束等待逻辑，没有随屏幕比例擅自修改视频循环/等待策略。
- Windows Tauri 原生独占全屏、真实多显示器/DPI 切换和真实 Spine 资源尚未实机验证。Spine 定位回归使用模拟资源；浏览器布局使用真实 Chromium。
- 安装后端依赖时原锁文件镜像返回 403，改用官方 PyPI 完成环境安装；未保留镜像切换产生的锁文件改动。
- 仓库已有 OpenAPI 与后端模型的其他历史不同步，本轮仅同步新增 `blank` 字段，避免将无关 schema 漂移混入改动。
