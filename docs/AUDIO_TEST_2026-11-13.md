# 音乐与语音播放验证

工作目录：`G:\NeoArchive`。在独立工程「音乐与语音独立测试」中验证，未修改之前的测试工程内容。本报告记录功能验证阶段，当时尚未提交、推送或发布。

## 发现与修复

- 音频 Cue 的 `volume` 之前仅存在运行时状态中，没有赋给实际 `<audio>` 元素。浏览器中设置 20% 和 60% 均读到 100%。现已同步实际音量，支持 0 静音，并约束到 0–1。
- 页面刷新后浏览器可能拒绝自动播放，原先没有反馈，点「从头播放」也不能恢复。现在显示「点击启用背景音乐 / 语音 / 音效」，点击后在用户手势中重试；运行时重新播放也会主动尝试启动音频。
- 音量改变保持同一媒体元素和播放位置，不重新载入音轨。媒体地址晚于运行时状态就绪时，也会重新绑定播放与结束逻辑。

## 验证结果

- 前端单元/组件测试：51 项通过，包含实际媒体元素的音量、静音、动态音量、语音起点/终点和自动播放失败后重试。
- 生产构建的浏览器回归：9 项全部通过。新增真实 Chromium 媒体测试覆盖：
  - BGM 与语音同时播放；语音在 0.5–1.5 秒选段结束。
  - BGM 20% 音量、自然循环；隐藏/显示对白不暂停 BGM。
  - 1.6 秒空白页期间 BGM 保持相同媒体元素，播放进度继续。
  - 同一 BGM 从 20% 改为 60% 后不倒回起点。
  - `audio.stop` 移除并暂停 BGM；音效以 15% 音量播放一次后停止。
  - 在要求用户手势的浏览器策略下，明确的启用声音按钮可以恢复音乐和语音。该用例关闭会触发页面脚本求值的 trace 快照，点击前通过无用户手势的 CDP 读取状态，同时确认页面尚未激活，避免测试工具提前解锁自动播放。
- `npm run build` 通过。仍保留原有大包体积提示。
